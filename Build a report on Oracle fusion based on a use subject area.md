# Build a Report in Oracle Fusion Based on a Subject Area

## 1. Log in to Oracle Fusion
1. Log in to **Oracle Fusion**.
2. Navigate to **Tools → Reports and Analytics → Browse Catalog**.

## 2. Create a Report Using a Subject Area
1. Click **Create → Report**.
2. Select **Use Subject Area**.
3. Choose the following subject area:

   `Payables Invoices - Transactions Real Time`

4. Click **Next**.
5. Select **Page Header**.
6. Choose **Table with Columns** as the report layout.
7. Click **Next**.

## 3. Configure the Report
1. Drag the required columns into the report table.
2. Uncheck **Show Grand Totals Row**.
3. Click **Finish**.

## 4. Save and Run the Report
1. Save the report with the following name:

   `SULAIMAN_reports_subject_area`

2. Click the **PDF icon** in the upper-right corner to view or run the report as a PDF.
