# Create Canvas and Data Block in Oracle Forms

1. Open **Oracle Forms Builder**.

2. Create a **Canvas** named:

   ```text
   CAN_EMP
   ```

3. Create a **Data Block** named:

   ```text
   EMP
   ```

   Then place it on the `CAN_EMP` canvas.

4. Save the form as:

   ```text
   SULAIMAN_EMP.fmb
   ```

5. Compile the form to create:

   ```text
   SULAIMAN_EMP.fmx
   ```
