# Create Lookup in Oracle EBS

Navigate to:

**Application Developer → Application → Lookups → Application Object Library**

Enter:

```text
Type: SULAIMAN_LOOKUP_DEPT
Meaning: SULAIMAN_LOOKUP_DEPT
Application: Application Object Library
Description: TEST FOR CREATING A LOOKUP FOR DEPARTMENT
Access Level: Extensible
```

Add the following lookup values:

| Code    | Meaning                | Description            |
| ------- | ---------------------- | ---------------------- |
| `FIN`   | FINANCE                | FINANCE                |
| `IT`    | INFORMATION TECHNOLOGY | INFORMATION TECHNOLOGY |
| `SALES` | SALES                  | SALES DEPT             |
| `PROD`  | PRODUCTION             | PRODUCTION             |
| `MKTG`  | MARKETING              | MARKETING              |

**Access Level:** Extensible — allows you to add more values later.
