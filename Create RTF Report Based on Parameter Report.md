# Create RTF Report Based on Parameter Report

1. Open **Oracle Reports Builder**.

2. Open the parameter report:

   ```text
   SULAIMAN_PARA_REP.rdf
   ```

3. Run the report and enter the required **DNO** parameter.

4. Save the output as:

   ```text
   SULAIMAN_PARA_REP.xml
   ```

5. Open **Microsoft Word**.

6. Go to the **BI Publisher** ribbon.

7. Select **Sample XML**.

8. Select:

   ```text
   SULAIMAN_PARA_REP.xml
   ```

9. Click **Table Wizard**.

10. Select **Table**.

11. Select the fields you want to display.

12. If required, group the report by:

```text
DEPTNO
```

13. Finish the Table Wizard.

14. Format the report as required.

15. Save the template as:

```text
SULAIMAN_PARA_REP.rtf
```

16. Review the template using **Preview** and select **PDF** to check the final output.
