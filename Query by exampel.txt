# Query by Example in EBS

1. Login to **Oracle EBS**.

2. Go to:
   **System Administrator → Security → User → Define**

3. Click:
   **View → Query by Example → Enter**

   The fields will change from **yellow to blue**.

4. In the **User Name** field, enter:

   ```text
   T%
   ```

5. Click:
   **View → Query by Example → Run**

6. All users whose names **start with T** will appear.
